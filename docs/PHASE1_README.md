# GUNA RENTCAR — 1차 공개 UI 구현 안내

본 패치는 승인된 개발 명세서 v1.0의 **1차 공개 페이지/디자인 검수** 범위만 구현합니다.

## 포함 경로 (10개)

`/`, `/cars`, `/services/monthly`, `/services/short-term`, `/services/long-term`, `/services/accident`, `/about`, `/faq`, `/contact`, `/privacy`.

## 주요 인터랙션

- PC 고정 헤더의 상담 메뉴(전화/요청 선택), 모바일 하단 1개 상담 버튼의 바텀시트 및 햄버거 메뉴
- 차량 카테고리, 모델 검색, 6시간/12시간 및 기간별 1일 요금, 가격 정렬, 가격 없는 차량의 전화 문의 표시, 카드 요금 펼침
- 모든 등록 차종을 서비스 페이지에 표시하며 월/장기/사고대차는 개별 전화 견적만 표시
- 대표 FAQ 아코디언, 전체 FAQ 카테고리, 검수용 리뷰 6개 + 6개 더보기
- 날짜 선택/직접 `YYYY-MM-DD` 입력, 필수값/기간 검증, 차량명 자동 채움, 개인정보 안내
- Google 지도 iframe lazy loading과 외부 지도 검색 링크
- 1차 개발에서는 승인된 활성 이벤트가 없어 이벤트 섹션을 숨김(이벤트 데이터·모달 컴포넌트는 포함)

## **실운영 기능이 아닌 부분**

1. **온라인 문의 전송 없음**: 문의 양식은 입력 형식 검증용입니다. 제출 데이터는 서버·Notion으로 전달하거나 저장하지 않습니다. 화면에도 이 사실이 명시됩니다.
2. **검증된 실제 후기가 없음**: 후기 카드는 예시 레이아웃이며 원문, 작성자, 작성일을 지어내지 않습니다.
3. **이미지 확인 필요**: `/public/images/cars`의 일부 이미지는 사용자가 제공한 차량 요금표 스크린샷을 자른 **차종 참고 이미지**입니다. 실제 보유 차량 사진이 아니므로 정식 공개 전 원본 사진으로 바꿔야 합니다. 이미지 없는 8개 모델은 플레이스홀더로 처리합니다.
4. **금액 확인 필요**: 사용자 제공 요금표 스크린샷에서 확인한 8개 차종의 6h/12h 및 기간별 1일 요금만 임시 데이터로 채웠습니다. 나머지는 `전화 문의`이며, 모든 금액은 실제 데이터 확인 후 교체해야 합니다. **1일/월별 요금을 임의로 만들지 않았습니다.**
5. 이벤트: 사용자 측에서 실제 기간/조건을 제공한 활성 이벤트가 없으므로 비노출입니다.
6. 네이버 플레이스 직접 리뷰 URL, 신규 네이버 블로그 URL, 사업자 세부 정보, 정식 개인정보처리방침, CMS와 Notion API, GA4 등은 **향후 단계**입니다. 확인되지 않은 URL/정보를 임의로 입력하지 않습니다.
7. Vercel Preview와 개발 환경은 기본 `noindex`/`robots disallow`입니다. 실운영 전 `NEXT_PUBLIC_PUBLIC_LAUNCH=true`를 변경 **하지 마세요**.

커밋 컨벤션: `추가:`(새 기능만), `고침:`(버그만), `변경:`(그 외 변경).
