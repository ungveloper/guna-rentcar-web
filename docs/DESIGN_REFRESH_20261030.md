# GUNA RENTCAR — 디자인 리프레시 (2026-10-30)

## 목표
기존 개별 `layout.tsx` + `page.tsx` 구조, `/cars` 차량 탐색 기능, 전화/검수용 문의 흐름을 유지하면서 20~30대 고객을 고려해 시각 디자인을 현대화합니다.

## 디자인 방향
- Drivoxe (drivoxe.framer.website): 큰 타이포, 차량 사진 중심의 시각 계층, 간결한 카드, 여백에서 영감. 레이아웃/문구/브랜드는 독자적으로 재설계.
- SK렌터카 (www.skdirect.co.kr): 서비스 분류 및 차량 탐색 흐름을 참고. 실시간 재고·온라인 예약처럼 존재하지 않는 기능은 추가하지 않음.
- rent-partner.co.kr: 자료 접근 불가하여 구체적인 디자인을 참조했다고 주장하지 않음.
- 브랜드 컬러: #AA895B, 보조: 딥 그린블랙 #1B2929, 바탕 #F5F7F4, 화이트.
- 모든 UI 스타일은 TSX의 Tailwind utility `className`으로 작성. `globals.css`는 `@import "tailwindcss";`만 유지.

## 변경 범위
- 메인 히어로, 하이라이트 차종, 렌트 서비스 카드, 브랜드 핵심 가치, FAQ, 상담 CTA
- 헤더/푸터, 모바일 메뉴/하단 상담 CTA
- 차량 카드, 검색/필터/가격 정렬 UI
- 서비스 상세 소개, 회사 소개, 후기 시안, FAQ, 상담/지도 화면
- 공통 페이지 히어로, FAQ 아코디언, 상담 모달 스타일

## 유지 범위
- 모든 실제 URL과 전용 route layout/page 파일
- 16개 차종 및 기존 참고 요금 데이터
- 모바일 상담, 유효성 검증 (실제 문의 미전송)
- 실시간 재고 및 예약/결제 기능 없음
- 후기 원문/작성자 허위 생성 없음

## 확인 사항
- 참고 자동차 이미지 8종은 소스 해상도가 낮고 공식 차량 사진으로 검증되지 않음. 실사진 교체 권장.
- 이벤트 및 실제 후기 등록, Notion/Firebase 연결은 후속 단계.
- npm lint/build, 11개 URL 스모크 테스트는 사용자 Mac에서 스크립트 실행 시 수행.
