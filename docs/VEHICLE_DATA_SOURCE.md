# 차량·요금 데이터 출처 및 이미지 관리

원본 자료: 사용자가 제공한 **건아렌트카 이용 요금 안내** PDF (4페이지).

- 총 **15개 차량 항목** (스타리아는 9인승/11인승이 동일한 한 항목에 기록되어 있음)
- 6시간·12시간 대여 요금은 1–3페이지 기재 모델에 적용
- **더뉴카니발 9인승**, **스타리아 9인승·11인승**은 원본에 **시간별 가격 없음**; UI에서는 `별도 문의` 표기
- 1~2일 / 3~6일 / 7일 이상 금액은 **일일 요금**으로 기록
- `data/vehicles.ts` 파일의 `rates`가 요금의 단일 원천
- 원본에 없는 연식, 트림, 연료, 옵션, 가격 할인 조건은 **추측해 채우지 않음**
- 원본 PDF에 차량별 공식 사진이 **포함되어 있지 않음**. 차량 카드에 제공된 공통 SVG는 *차급 참고용 이미지*로 표기함. 실제 제조사 이미지의 상업적 사용 허락이 확인되면 `public/images/vehicles/`에 저장하고 `image` 및 `imageAlt` 값을 변경
- 히어로의 `public/images/hero/studio-sedan.webp`은 **AI 생성된 콘셉트 이미지**이며 특정 실제 보유 차량을 설명하는 사진이 아님
- `data/reviews.ts`: 이용허락이 확인된 실제 리뷰만 등록하며 조작된 리뷰 금지

## 원본 PDF 모델 목록

- 1p: 더뉴모닝, 더뉴레이, 아반떼 CN7, 더뉴K3(이하 2p 연속)
- 2p: 더뉴K5, 더뉴말리부, 쏘나타 DN8, 쏘나타 DN8 디엣지, 그랜저 GN7(이하 3p 연속)
- 3p: G80, 셀토스, 투싼, GV80
- 4p: 더뉴카니발 9인승, 스타리아 9인승·11인승

## 개발 시 유의사항

- `Cache Components` 활성 상태에서 서버 컴포넌트 본문 내 매 렌더 `new Date()` 사용 금지.
- 원페이지 `/` 고유 canonical 유지, 차량별 고유 URL은 이번 범위 밖.
- 모든 전화 연결은 `components/PhoneLink.tsx`로 추적.
