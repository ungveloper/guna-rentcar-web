# 차량·요금·사진 데이터 관리

## 출처

- 기준 요금: 사용자가 제공한 **건아렌트카 이용 요금 안내** PDF 4페이지 (2026-10-13 전달)
- 차량 사진: 사용자가 제공한 **아카이브(2).zip**의 모델별 WebP 15개 (이번 업데이트)
- 각 사진은 `public/images/vehicles/<차량 ID>.webp`에 저장되며 `data/vehicles.ts`의 ID와 연결됩니다.

## 데이터 규칙

- 총 15개 모델 항목(스타리아는 9·11인승 통합 표기)
- 시간별 요금: 6시간/12시간. **카니발, 스타리아는 원본에 시간별 요금이 없어 전화 문의로 표시**.
- 기간별 1일 요금: 1~2일, 3~6일, 7일 이상. 기간별 금액은 **총액이 아니라 하루당 가격**.
- 차량마다 색상·트림·연식·옵션은 실제 대여 차량과 다를 수 있으므로 광고 카피에 확정 정보로 사용하지 않습니다.
- 임의 요금과 실제 고객 후기 생성 금지. 변경 시 PDF 자료 또는 업체 확인이 필요합니다.
- 사진 재배포 및 상업적 사용 권리는 홈페이지 정식 운영 전에 소유자 확인이 필요합니다. **사진 파일을 제공받았다는 사실 자체가 라이선스 확보를 의미하지 않습니다.**

## 웹사이트 이미지 사용

- Hero: `g80.webp`; Showcase: `gv80.webp`; Story: `grandeur-gn7.webp`; Contact: `tucson.webp`.
- Fleet 및 요금 모달: `data/vehicles.ts`의 `image` 경로를 사용하므로 모델별 사진이 동일하게 노출됩니다.
- Open Graph: `public/images/og/cover.png`는 제공 사진 기반의 브랜드 공유용 대표 이미지입니다.

## 개발 및 SEO

- Next.js 16 Cache Components를 유지하며 서버 렌더에서 `new Date()` 등 가변 현재시간 계산을 하지 않습니다.
- `/` 경로가 유일한 페이지이며 차량별 개별 URL은 생성하지 않습니다.
- 전화 CTA는 `PhoneLink`를 통해 추적합니다. `data/reviews.ts`는 검증된 원문만 등록합니다.
