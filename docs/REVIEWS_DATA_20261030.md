# 건아렌트카 고객 후기 적용 안내

- 자료: 사용자 제공 `review.txt`, 총 145건. 작성자 닉네임, 내용, 작성 날짜 표기, 네이버 리뷰 프로필 URL 저장.
- 공통 데이터: `app/_lib/review-data.ts` (원문 데이터), `app/_lib/site-data.ts`에서 export.
- 대표 후기: 12건. 친절, 차량 청결, 재방문, 가족여행, 일정 조율, 사고대차, 장기렌트 등 서로 다른 경험을 우선 선정.
- 메인(`/`): 대표 3건 표시. 회사 소개(`/about`): 대표 3건 표시.
- 후기(`/reviews`): 대표 12건, '전체 후기 보기' 누르면 전체 145건을 18건씩 펼쳐 표시.
- 출처 안내: 업로드 파일의 링크는 **개별 리뷰 고유 URL이 아닌 작성자 리뷰 프로필 URL**입니다. 버튼도 이 사실대로 표기합니다.
- 별점/평점 정보는 제공되지 않아 어떤 수치나 별점도 표시하지 않습니다.
- 작성 날짜에 연도가 없으면 임의 보정하지 않고 원문 표기 그대로 유지합니다.
- 실제 리뷰의 내용과 닉네임은 변경하지 않았습니다. 카드에서는 줄 수만 줄여 보여줍니다.
- 사용자 제공 자료는 외부에서 재검증하지 않았으며, 재게시 권한 등은 운영자가 확인해야 합니다.
- 기존 라우팅 구조, Tailwind JSX 클래스, 요금·보험·이벤트·문의 로직은 변경하지 않습니다.
